📌 Projeto — Sistema de Cadastro, Login e Notícias Personalizadas

🎯 Objetivo

Este projeto tem como objetivo criar uma aplicação web onde o usuário pode se cadastrar, realizar login e receber notícias personalizadas de acordo com seus interesses (ex.: esporte, tecnologia, etc.).
Além disso, o sistema terá funcionalidades sociais, como comentários e curtidas, que poderão ser visualizadas por outros usuários.


---

⚙️ Funcionalidades atuais

Cadastro de usuários

Login com validação via API em PHP

Geração e validação de token JWT para autenticação

Front-end em React consumindo as APIs



---

🚀 Tecnologias utilizadas até agora

Front-end: React, JavaScript, CSS3, HTML5

Back-end: PHP (APIs próprias)

Banco de dados: MySQL

Autenticação: JWT (JSON Web Token)

Controle de versão: Git/GitHub



---

🛠️ Próximas implementações

API para listar notícias personalizadas com base nos interesses do usuário

Sistema de comentários nas notícias

Sistema de curtidas visíveis para todos os usuários
